cache dirs on this machine (cold Trivy DB), classic PAT with `public_repo` only,
repo `snyk-labs/nodejs-goof` (public, third party; added by name).

- Cold run downloaded the Trivy DB (1.6 GB) in ~11 s on this connection. On a
  50 Mbit/s line that download alone is ~4–5 min, so the 5-minute target holds on
  fast connections and is tight on slow ones (README already warns about the DB).
- Result: 185 findings (25 critical, 79 high, 65 medium, 12 low; 2 IaC; 2 licence),
  scanner_runs trivy 11.0 s / gitleaks 0.2 s; workspace removed after the scan;
  test connection and its keyring entry deleted at the end.

  and `brew install` right after `v0.1.0` is tagged.

  so public repos of others could not be added from the UI (added "Add owner/repo");
  dashboard header total excluded `unknown`.
